# Sample data

- `sample_tbdem.csv`: four-round World Schools-style example with three adjudicators per speech, reply speeches, and an iron/double-speech case.
- `sample_wudc.csv`: two-round British Parliamentary example with finalized placements and speaker scores.
- `template_tbdem.csv` and `template_wudc.csv`: empty files ready for tournament data entry.

These files contain fictional teams and speakers and are intended only for testing and demonstrations.
